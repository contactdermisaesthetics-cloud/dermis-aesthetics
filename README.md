# Dermis Aesthetics Website

Professional static website for Dermis Aesthetics, built with organized HTML, CSS and JavaScript.

## Pages

- `index.html` - Home
- `about.html` - About
- `treatments.html` - Treatments
- `qa.html` - Q&A / FAQ
- `contact.html` - Contact with Google Map embed

## Project Structure

```text
.
├── index.html
├── about.html
├── treatments.html
├── qa.html
├── contact.html
├── logo.png
└── assets
    ├── css
    │   └── styles.css
    └── js
        ├── site-data.js
        └── app.js
```

## Where To Edit

Most clinic content is centralized in:

```text
assets/js/site-data.js
```

The header logo is served from:

```text
logo.png
```

Use a transparent or tightly cropped logo file here so the navbar logo stays sharp and visible.

Update these placeholders before publishing:

- `https://example.com` in `index.html`
- `mapEmbed` in `assets/js/site-data.js` if you have the exact Google Business Profile map link

## Local SEO Checklist

Use the exact same clinic name, address and phone number on:

- Google Business Profile
- Justdial
- Practo
- Sulekha
- IndiaMART
- Facebook
- Instagram
- Bing Places

Consistency improves local search trust.
